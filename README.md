# 🔐 SQL Injection Detection System

### 🛡️ Securing Databases Through Smart Attack Detection

## 📌 About the Project

The **SQL Injection Detection System** is a security-based project developed to identify and prevent SQL Injection attacks. It helps protect databases from malicious queries, unauthorized access, and potential data breaches.

The project focuses on improving database security through AES-256 encryption and a double-layer security mechanism.
